# 嘉義海線親子放電一日遊

這個子目錄包含可直接發布到 GitHub Pages 的靜態行程頁，頁面與圖片都集中在同一處。

## 檔案

- `index.html`：手機與桌機版行程頁。
- `assets/high-heel-church.jpg`：高跟鞋教堂封面圖。
- `assets/suantou-wufen-train.jpg`：蒜頭糖廠五分車照片。
- `assets/dongshi-oyster-farm.jpg`：東石蚵田照片。
- `assets/dongshi-oyster-trellis.jpg`：東石蚵棚與觀光船照片。
- `assets/budai-fishing-port.jpg`：布袋第三漁港照片。

## 目前待確認

- 出遊日期。
- 上午選擇「向禾休閒漁場」或「咩咩上樹萌寵樂園」。
- 東石海鮮餐廳與團體訂位。
- 蒜頭糖廠五分車的實際班次、路線與預約狀態。

## 行程提醒

- 高跟鞋教堂與好美里 3D 彩繪村排在 65 分鐘內，屬緊湊段；若午餐延誤，建議二選一。
- 向禾休閒漁場的體驗採預約制，內容以店家當日方案為準。
- 五分車班次依日期、平假日與預約狀況不同，不應把 16:30 視為已確認發車時間。
