# 2026.10.25 嘉義海線親子一日遊

本子目錄是獨立 GitHub Pages 行程頁，公開網址：

https://bhevantw.github.io/chiayi-coast-family-trip/

## 行程定案

- 日期：2026 年 10 月 25 日（星期日）
- 人數：34 人
- 09:00 嘉義市民生北路 256 號出發
- 10:00–11:00 好美里 3D 彩繪村
- 11:20–11:50 高跟鞋教堂
- 12:00–13:30 布袋英賓海產餐廳（嘉義縣布袋鎮永安里 359 號）
- 14:10–15:40 咩咩上樹萌寵樂園
- 15:50–17:20 蒜頭糖廠蔗埕文化園區
- 18:00 回到民生北路 256 號

## 出發前確認

- 英賓海產餐廳（永安里 359 號）：34 人桌數、菜色、兒童椅、素食與過敏需求。
- 咩咩上樹：團體票務與入園安排。
- 蒜頭糖廠：現行假日故宮南院線有 16:20 蒜頭站發車班次；仍需向園區確認 10/25 當日班次、團體安排與餘位。
